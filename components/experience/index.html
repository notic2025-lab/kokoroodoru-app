FOUR MOMENTS

01 — 視線の設計

最初は景色をそのまま見せる。入る操作をきっかけに、足元から光が伸びる。

水が湧き、輪が重なる。人が集まる場所の目印。

なぜ、この形なのか ↓

DESIGN INTENT — 05

同じ場所に、
昼と夜の表情を。

昼は触れられそうな、色と輪郭のある目印。
夜はその輪郭から、光がほどけていく。
場所の形は同じまま、時間で素材を変えます。

DAY / 06:00—18:00

日なたでは、形を手がかりに。

濃い面色、白い縁、接地する影。背景が明るくても暗くても輪郭が残る、マットな立体の目印。案内の帯と文字も、不透明な面で支えます。

NIGHT / 18:00—06:00

暗がりでは、灯りを手がかりに。

細い流れ、地面の波紋、控えめな発光。昼と同じ形から光がほどけます。文字の面は暗く保ち、景色と光を一緒に見られるように。

01 / 水 / 集う

待ち合わせの泉

水が湧き、周囲に輪が広がる。人が集まり、また街へ向かう場所。

02 / 火 / ひと息

喫煙所の熾火

強く燃やさず、低い位置で揺らぐ。立ち止まって過ごす場所の、小さなぬくもり。

03 / 波 / 共鳴

ステージの共鳴

水平に重なる波が、ゆっくり広がる。人と音が響き合う場所。音声には未連動。

04 / 気 / ほどける

キッチンの湯気

細い線が上にほどけていく。食べものの温度と、人が集まる気配。

05 / 境 / 切り替わる

入口の光の境界

地面から立ち上がる薄い輪郭。ここを越えて街に入る、という切り替わり。

06 / 灯 / 留まる

記憶の残り灯

小さな光が異なる高さで留まる。同じ場所にいた誰かを感じる。

01 / 接地

地面が、光を受け止める。

道路と同じ遠近感。足元の淡い反射。実景の明るさに応じた光量。空間との接点から、そこにある感覚をつくる。

02 / 視線

迷う瞬間だけ、案内を強く。

歩く間は細い光と次の一手。分岐では方向を明確に。到着したら道順を消し、場所と人が見える余白を返す。

03 / 余韻

その人がいた、気配を残す。

到着を派手に祝う代わりに、一つの灯りを置く。誰かの記憶と居合わせることを、この街の小さな楽しみにする。

このプロトタイプで確かめること
